# 稳态：反应舱

Godot 4.7.2 的单关卡 2D 平台解谜 Demo。当前关卡有三个连续舱段：力学检修、反应与相变、双路线平衡控制。关卡长度 6144 px，逻辑画面 1152×648。

## 运行

双击同目录的 `run_demo.cmd`，或在 Godot 中打开**本目录**的 `project.godot` 并按 F6 运行 `main.tscn`（F5 运行整个工程）。

`subject-game` 是另一个素材工作目录，游戏主工程在外层 `biggamejam261002`。

也可以在本目录执行：

```powershell
& '..\Godot_v4.7.2-stable_win64.exe' --path .
```

## 操作

| 操作 | 输入 |
|---|---|
| 移动 | A/D 或左右方向键 |
| 攀爬 | W/S 或上下方向键 |
| 蹲伏 | S / 下方向键（梯子外） |
| 跳跃 / 二段跳 / 梯子跳离 | Space |
| 选择试剂 | 1–3 或滚轮 |
| 朝前投放 | Q（冷却胶囊略向下） |
| 鼠标瞄准投放 | 左键 |
| 附近吊台重力扰动 | E |
| 鼠标指定重力扰动 | 右键 |
| 恢复当前检查点及机关 | R |
| 能力面板 | Tab |
| 暂停 / 返回 | Esc |

## 游玩路线

1. 把橙色配重推到圆形压板，启动吊台并开启隔离门。弹簧、梯子和上层样本是奖励路线；主路经过检修井到达下一检查点。
2. 绿色盐酸解除碳酸钙密封。检查点解锁蓝色冷却胶囊及重力扰动，用胶囊冻结水槽 6 秒，再跳过或绕过腐蚀区。
3. 最后一段有两种通关方法：上层用重力吊台、配重和铁片电磁锁；下层用冰桥和盐酸锁扣。进入出口显示本次实验统计。

试剂补给不限次数；R 重建当前舱段，保留已解锁能力和已收集样本。九个样本均为可选项，拾取恢复 12 稳态。菜单中的“重新开始整关”清空本次进度。
