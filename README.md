# 理化实验舱 Demo

基于 Godot 4 的 2D 平台跳跃原型，用一张小型实验舱地图验证平台跳跃、物理机关和化学交互。

## 运行

1. 使用 Godot 4.3 或更高版本打开项目目录。
2. 运行 `main.tscn`（项目启动场景已配置）。

也可以在 Windows 下直接执行：

```powershell
.\engine\Godot_v4.7.2-stable_win64.exe --path .
```

## 操作

- `A/D` 或方向键：移动
- `Space`：跳跃
- `Q`：投掷盐酸
- `R`：重置 Demo

## Demo 路线

推动橙色配重压住绿色开关，打开闸门；到达碳酸钙岩石前按 `Q` 投掷盐酸，溶解岩石后继续前进。粉色腐蚀区会持续降低稳态值。
