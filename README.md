# 稳态：反应舱

Godot 4.7.2 的单关卡 2D 平台解谜 Demo。当前关卡有三个连续舱段：力学检修、反应与相变、双路线平衡控制。关卡长度 6144 px，逻辑画面 1152×648。

## 运行

双击同目录的 `run_demo.cmd`，或在 Godot 中打开**本目录**的 `project.godot` 并按 F6 运行 `main.tscn`（F5 运行整个工程）。

`subject-game` 是另一个素材工作目录，游戏主工程在外层 `biggamejam261002`。

也可以在本目录执行：

```powershell
& '..\Godot_v4.7.2-stable_win64.exe' --path .
```

## 游玩路线

1. 把橙色配重推到圆形压板，启动吊台并开启隔离门。弹簧、梯子和上层样本是奖励路线；主路经过检修井到达下一检查点。
2. 绿色盐酸解除碳酸钙密封。检查点解锁蓝色冷却胶囊及重力扰动，用胶囊冻结水槽 6 秒，再跳过或绕过腐蚀区。
3. 最后一段有两种通关方法：上层用重力吊台、配重和铁片电磁锁；下层用冰桥和盐酸锁扣。进入出口显示本次实验统计。

试剂补给不限次数；R 重建当前舱段，保留已解锁能力和已收集样本。九个样本均为可选项，拾取恢复 12 稳态。菜单中的“重新开始整关”清空本次进度。

反应舱的上层训练阳台有两只氧化靶，命中补充氧能量；蓄力释放也补充氧能量，沿用远端版本规则。靶子被击倒后 2 秒恢复。氧攻击不替代试剂和配重机关。死亡、R 和整关重启均恢复氧能量并清除战斗冷却。K 是跳跃键，Space 不再用于跳跃。

## 像素调色与动画工作台

在 Godot 中打开 `tools/pixel_workbench.tscn` 并按 F6，使用 32 色调色板绘制 32×48 像素帧，支持多帧、网格、洋葱皮及播放预览。PNG、精灵条、GPL 和 JSON 调色板导出到 `user://pixel_workbench/`。当前角色采用远端人物贴图，按 1 倍比例匹配原关卡碰撞体。

## 氧元素像素子弹与压缩气枪

J 普攻与 I 蓄力攻击使用“双氧脉冲”像素动画：O₂ 双球核心、气泡尾迹、压缩气壳和命中消散。打开 `assets/chemistry_bullets/oxygen_v2/preview.html` 可查看动画及原尺寸效果；设计说明见同目录 `DESIGN.md`。

武器名为**压缩气枪**。气弹会受到空气密度、风、平方阻力、混合和浮力影响，距离越远伤害越低；耗尽后成为无伤害气雾。游戏 HUD 可切换常温、稀薄空气、冷空气、热氧弹与气流环境，查看当前密度和枪口初速。物理设定见 `COMPRESSED_AIR_GUN.md`，轨迹预览见 `assets/chemistry_bullets/oxygen_v2/air_gun_preview.html`。
