# 稳态：反应舱

Godot 4.7.2 的四元素武器与 2D 平台角色原型。当前关卡有三个连续舱段：力学检修、反应与相变、双路线平衡控制。关卡长度 6144 px，逻辑画面 1152×648。

## 运行

双击同目录的 `run_demo.cmd`，或在 Godot 中打开**本目录**的 `project.godot` 并按 F6 运行 `main.tscn`（F5 运行整个工程）。

`subject-game` 是另一个素材工作目录，游戏主工程在外层 `biggamejam261002`。

也可以在本目录执行：

```powershell
& '.\engine\Godot_v4.7.2-stable_win64.exe' --path .
```

## 操作

背景音乐使用 `music/旧舱新发现.mp3`，进入游戏自动循环播放，暂停菜单与检查点恢复期间保持连续播放。默认音量为 −12 dB，可在 `lab_audio.gd` 的 `music_player.volume_db` 调整。

| 操作 | 输入 |
|---|---|
| 移动 | A/D 或左右方向键 |
| 攀爬 | W/S 或上下方向键 |
| 趴下爬行 | S / 下方向键（梯子外） |
| 跳跃 / 二段跳 / 梯子跳离 | K |
| 水平冲刺 | L（梯子上和蹲伏时禁用） |
| 上一个 / 下一个元素 | Q / E（氢 → 氧 → 碳 → 铁，循环切换，默认氧） |
| 当前元素普通攻击 | J |
| 当前元素技能 | U（消耗 25 元素能量，冷却 4 秒） |
| 当前元素蓄力弹 | 按住 I，松开释放 |
| 当前元素大招 | O（消耗 100 元素能量） |
| 恢复当前检查点及机关 | R |
| 能力面板 | Tab |
| 暂停 / 返回 | Esc |

## 当前角色功能

角色能力仅保留四元素与 J/K/L/U/I/O。基础移动、攀爬、趴下爬行及暂停、恢复菜单沿用原操作。投掷道具、1–3 快捷栏、滚轮选择、鼠标投掷和重力技能已经取消。

氢、氧自动装备压缩气枪与各自气瓶；碳、铁自动装备固体发射器与各自弹匣。J 和 I 分别使用当前元素的普通、蓄力飞行与命中动画。氢气更易混合、上浮；氧气的浮沉由温度与混合决定；固体弹受重力和空气阻力下坠。命中氢气只产生气团破裂，不默认点火。

U / O：氧沿用范围冲击 / 纯氧领域；氢、碳、铁暂采用三发普通弹 / 五发蓄力弹的扇形射击。四元素共用能量和技能冷却，切换不会刷新；切换取消正在进行的蓄力。蓄力释放及命中训练靶补充能量。R 保留元素选择，重新开始整关恢复默认氧。

关卡布局与机关保留旧版，本次不改其能力依赖；旧通关路线见 `LEVEL_DESIGN.md` 的历史记录。当前验证范围为角色、武器和独立机关模块。

## 像素调色与动画工作台

在 Godot 中打开 `tools/pixel_workbench.tscn` 并按 F6，使用 32 色调色板绘制 32×48 像素帧，支持多帧、网格、洋葱皮及播放预览。PNG、精灵条、GPL 和 JSON 调色板导出到 `user://pixel_workbench/`。当前角色采用远端人物贴图，按 1 倍比例匹配原关卡碰撞体。

## 氧元素像素子弹与压缩气枪

四元素战斗现使用 `assets/chemistry_bullets/four_elements/` 的飞行、命中和武器射击精灵条。打开同目录 `design_book.html` 查看素材与动画；完整设定见 `FOUR_ELEMENTS_DESIGN.md`。旧氧弹预览仍保留作设计参考。

武器名为**压缩气枪**。气弹会受到空气密度、风、平方阻力、混合和浮力影响，距离越远伤害越低；耗尽后成为无伤害气雾。游戏 HUD 可切换常温、稀薄空气、冷空气、热氧弹与气流环境，查看当前密度和枪口初速。物理设定见 `COMPRESSED_AIR_GUN.md`，轨迹预览见 `assets/chemistry_bullets/oxygen_v2/air_gun_preview.html`。
