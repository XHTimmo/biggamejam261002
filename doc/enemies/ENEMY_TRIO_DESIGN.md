# 三种新敌人设计

三种敌人沿用科技像素风、32 色实验室色盘和四元素武器系统。它们分别承担近战压迫、空中骚扰、阵地封锁三种战斗职责，首次出现时各放置一只，避免同屏信息过载。

## EN-02 锈壳潜行虫 Rust Crawler

锈壳潜行虫是从排水沟金属碎屑中孵化的低矮节肢污染体。侧面轮廓由深蓝外壳、灰蓝甲片和橙色锈核组成，移动时身体贴地，前端锈核朝向玩家。

| 项目 | 设定 |
|---|---|
| 定位 | 快速近战、短距离突进 |
| 生命 | 155 |
| 接触伤害 | 24 |
| 移动速度 | 102 px/s |
| 感知范围 | 310 px |
| 攻击节奏 | 0.34 s 蓄力 → 0.28 s 突进 → 0.46 s 收招 |
| 可读前摇 | 锈核变黄，背甲压低并出现半圆警示弧 |
| 推荐投放 | Zone 01 中段平台，和泥团组成快慢组合 |

元素响应：氢 1.15 倍，氧 0.75 倍，碳 0.90 倍，铁 1.35 倍。氧适合稳定削弱，铁适合高爆发；氢会把它推离玩家但伤害较高。碳只造成轻微减速，不能替代控制型敌人。

动画节点：待机每 0.4 秒触须抖动一次；移动以 6 帧循环表现左右足交替；蓄力 5 帧逐步压低身体；突进 4 帧拉长轮廓；命中后 3 帧甲片震动；死亡 8 帧拆散为锈色像素。

## EN-03 氧雾漂浮体 Oxygen Wisp

氧雾漂浮体是失控氧气凝结出的半透明浮游体。它没有脚，依靠两条青色尾焰上下漂移；发射时核心收缩，随后向玩家射出一条短促的高亮氧线。

| 项目 | 设定 |
|---|---|
| 定位 | 空中远程骚扰 |
| 生命 | 90 |
| 远程伤害 | 16 |
| 远程范围 | 360 px |
| 感知范围 | 430 px |
| 攻击间隔 | 1.8 s |
| 移动节奏 | 2.2 Hz 上下漂移，保持出生区域高度 |
| 推荐投放 | Zone 02 水槽上方，迫使玩家注意垂直空间 |

元素响应：氢 0.85 倍，氧 0.55 倍，碳 1.25 倍，铁 1.10 倍。氧对同类雾体效果很差，碳是最稳定的克制手段；氢有轻微击退，适合把它推离水槽边缘。

动画节点：待机 8 帧呼吸循环；蓄力 4 帧核心收缩；发射 3 帧尾焰向后拉伸；受击 3 帧白闪；死亡时半径扩大后收缩成青色粒子。

## EN-04 铁幕哨卫 Iron Sentinel

铁幕哨卫是净化核心留下的自动防御单元。它是固定位置的低矮炮台，深蓝外壳包住黄色瞄准镜，顶部生命条下方另有一条青色护盾条。

| 项目 | 设定 |
|---|---|
| 定位 | 阵地封锁、护盾炮台 |
| 生命 | 210 |
| 护盾 | 80，护盾存在时先吸收伤害 |
| 远程伤害 | 22 |
| 远程范围 | 460 px |
| 攻击间隔 | 2.2 s |
| 可读前摇 | 黄色瞄准镜亮起，向玩家方向出现短线 |
| 推荐投放 | Zone 03 出口前，与泥团形成最后一道火力线 |

元素响应：氢 1.10 倍，氧 0.90 倍，碳 1.35 倍，铁 0.55 倍。碳先破护盾再削生命最有效；铁几乎无法快速破盾，避免玩家只使用单一元素。

动画节点：待机 6 帧机械微摆；瞄准 4 帧黄色镜头逐格点亮；发射 3 帧炮口闪光；护盾受击 2 帧青色环波；护盾破裂 6 帧环波断裂；死亡 8 帧外壳碎片下落。

## 组合与难度节奏

Zone 01 先教玩家用氧处理锈壳潜行虫，再用铁快速击破；Zone 02 让氧雾漂浮体站在水槽上方，玩家需要在移动和瞄准之间切换；Zone 03 的铁幕哨卫放在出口前，配合四只脏脏泥团形成“先清杂兵、再破护盾、最后冲刺”的终局节奏。

三个新敌人都接入 `defeated` 信号，清除所在区域的全部敌人后才会完成区域目标。
